# 🛒 BlinkIT Grocery Sales Dashboard - Power BI

This repository contains my first Power BI project, built using a grocery sales dataset from BlinkIT. The dashboard delivers key insights into sales performance, outlet trends, product categories, and customer ratings — helping businesses make informed decisions.

## 📈 Key Metrics

- ✅ **Total Sales**: $1.2M  
- ✅ **Average Sales per Item**: $141  
- ✅ **Customer Ratings**: 3.9 / 5  

## 📌 Highlights

- **Outlet Performance**: Supermarket Type1 leads, contributing over 65% of total sales.
- **Product Trends**: Regular fat products make up 64.6% of sales; fruits and snack foods are top-performing.
- **Geographical Insights**: Tier 3 outlets show strong performance in smaller cities.
- **Growth Insight**: Sales peaked in 2018, showing a strong growth phase.

## 🧰 Tools Used

- Microsoft Power BI
- Data modeling (Power Query, DAX)
- Data visualization best practices
